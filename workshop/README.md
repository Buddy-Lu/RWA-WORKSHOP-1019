# 課堂操作入口

上課請依順序點選，跟著老師做到當前步驟即可。

| 步驟 | 內容 |
|---|---|
| [01 準備錢包](steps/01-wallet.md) | 安裝 MetaMask、切換 Sepolia |
| [02 發行與轉帳](steps/02-token.md) | 複製完整合約到 Remix，發幣並轉給同學 |
| [03 看懂台股合約](steps/03-factory.md) | 跟老師看 StockToken 與 Factory |
| [04 啟動操作網頁](steps/04-frontend.md) | 下載、解壓縮，用網頁操作自己的幣 |
| [05 體驗台股代幣](steps/05-stock.md) | 授權、買入、檢查結果 |
| [記錄成果](steps/06-finish.md) | 保存地址與交易，整理學到的概念 |

## 已下載，想啟動課堂網頁？

在儲存庫根目錄（看得到 `workshop`、`onchain`、`frontend` 的位置）開終端機，執行：

```bash
node workshop/frontend/serve.mjs
```

再開啟 http://127.0.0.1:4173。第一次操作請先看 [第 04 步的完整說明](steps/04-frontend.md)。
