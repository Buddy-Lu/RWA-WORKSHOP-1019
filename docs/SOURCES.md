# 教材來源

本庫程式以使用者提供的 FormosaX 完整作品包為基礎。課程的規則、數字例子與權限敘述以實際 Solidity 與 JavaScript 為準，舊版開發文件保留在 `original/`。

## 官方閱讀

- [Ethereum 智能合約](https://ethereum.org/developers/docs/smart-contracts/)
- [Ethereum PoS](https://ethereum.org/developers/docs/consensus-mechanisms/pos/)
- [Ethereum Layer 2](https://ethereum.org/layer-2/)
- [ERC-20 規格](https://eips.ethereum.org/EIPS/eip-20)
- [OpenZeppelin 5.0.2 原始碼](https://github.com/OpenZeppelin/openzeppelin-contracts/tree/v5.0.2)
- [Remix 部署與環境](https://remix-ide.readthedocs.io/en/latest/run.html)
- [MetaMask 安裝](https://support.metamask.io/start/getting-started-with-metamask/)
- [ethers v6](https://docs.ethers.org/v6/getting-started/)

Remix 與 MetaMask 操作頁於 2026-10-18 查核。介面可能更新，以官方功能與目前畫面為準。講稿亦參考使用者提供的 Daniel Huang／BSOS 區塊鏈課程教材；原 PDF 不在公開儲存庫散布。

ClassToken 教材使用固定 OpenZeppelin 5.0.2；精簡前端附 ethers 6.13.4，授權檔分別保留在 vendor 目錄。原專案依其 package-lock 安裝，不把不同套件版本視為完全相同的教材環境。
