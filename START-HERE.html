RWA WORKSHOP 1019 · 完整原始碼資料包

開啟完整操作手冊：設定 .env → 部署自己的幣 → 餵價檢查 → Vercel

把台股代幣平台
變成你自己的作品。

先解壓縮 ZIP，接著完成下面三步。這裡啟動的是完整 React 網站，與課堂的精簡操作網頁不同。

本包附公開 Sepolia 合約地址，能建立同款介面與連線方式；不會複製老師的錢包、餘額或管理權限。買賣仍取決於鏈上價格與儲備。網站上線不代表 feeder、keeper 已啟動。

01 安裝一次

  1. 安裝 Node.js 24 LTS，保留 npm 安裝選項。
  2. 完整解壓縮，把整個資料夾放在自己的電腦；不要在 ZIP 預覽視窗裡執行。
  3. Windows：雙擊 01-install.cmd。等待出現 Ready。第一次需網路下載套件，可能花數分鐘；失敗請保留錯誤訊息。

這一步只安裝網站依賴，不需要填私鑰。

02 打開完整網站

雙擊 02-start.cmd，瀏覽器會開啟 http://127.0.0.1:5173。保留黑色終端機視窗，結束時按 Ctrl+C。

先看各頁面，再連接 MetaMask，網路選 Sepolia。需要送交易時才使用測試 ETH。出現 stale price 或交易失敗，先依課程指示確認鏈上狀態，重開網站不會更新 Oracle。

用 VS Code 開啟整個資料夾，修改 frontend/src/routes/ 的頁面，存檔後瀏覽器會更新。

macOS／Linux：在資料夾開終端機，依序執行：
node scripts/student-start.cjs install
node scripts/student-start.cjs start

03 建置，再部署 Vercel

先雙擊 03-build.cmd，確認出現 Build passed。

  1. 在 課程 GitHub 按 Fork 建立自己的副本。若有修改，先把改動提交到自己的副本；只在本機修改不會自動上傳。
  2. 登入 Vercel，匯入你自己的 GitHub 儲存庫。
  3. 部署設定如下，確認 Root Directory 是 frontend 後再按 Deploy。
設定填入
Framework PresetVite
Root Directoryfrontend
Install Commandnpm ci
Build Commandnpm run build
Output Directorydist
Node.js Version24.x

部署的是整份 frontend 原始碼，包含 api/。只上傳 dist 會缺少行情 API。

想直接上傳本機修改版：在 frontend 資料夾的終端機執行 npx vercel，依提示登入並建立預覽。確認預覽後執行 npx vercel --prod。首次執行會提示安裝 CLI。

基本頁面與瀏覽器錢包不必填 API key。選配：VITE_WC_PROJECT_ID 用自己的 WalletConnect project ID；VITE_RPC_URL 是會公開在瀏覽器的 RPC URL。AI 評語使用 ANTHROPIC_API_KEY，只能放 Vercel 伺服器環境變數，不加 VITE_。沒有 AI key 時其他功能仍可用。

上線後檢查：首頁能開啟、進入交易頁後重新整理不會 404、/api/twse 回 JSON。空物件表示行情來源當下不可用；不代表有最新報價。另確認錢包是 Sepolia。
